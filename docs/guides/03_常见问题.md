# 常见问题

## 为什么不把每个作图 Skill 单独拆包？

客户实际需要的是完成一张图，而不是只会做一个局部动作。作图通常需要配色、排版、字体、构图、场景和图片处理一起配合，所以这个包做成综合包更合理。

## 主图和海报怎么选 Skill？

主图优先用 `graphic-design`、`product-mockup`、`ad-creative-design`。海报优先用 `poster-design`，社媒图优先用 `social-media-graphic`。

## 抠图是不是必须用？

不是。只有你有原图素材，并且需要换背景、透明底或重新组合时，才用 `background-removal`。

## 图片不好看怎么办？

先不要急着重做。先检查需求卡：主题、尺寸、主标题、卖点、风格是否清楚。很多问题来自需求没有拆清楚。
