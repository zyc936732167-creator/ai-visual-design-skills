# 案例：商品主图作图

## 原始需求

我要做一个资料包的主图，想让买家一眼看懂里面有模板、教程、案例，风格要清爽专业。

## 整理后的指令

请设计一张方形商品主图，主题是“视觉作图综合 Skill 包”。画面主体是电脑屏幕和资料文件夹，屏幕里展示海报、社媒图、广告图、商品展示图四种示例缩略图。主标题：AI视觉作图综合Skill包。副标题：海报 社媒图 广告图 商品展示图。风格清爽专业，白色背景，蓝色、青绿色、橙色点缀。文字要清楚，不要平台标志，不要人物头像，不要效果承诺。

## 适合调用的 Skill

- `graphic-design`
- `ad-creative-design`
- `product-mockup`
- `layout-composition`
- `typography`
- `color-palette`
