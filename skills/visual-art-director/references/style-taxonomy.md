# 视觉风格谱系（Style Taxonomy）

定方向时从本表选 1 个主锚点（最多叠 1 个次要气质）。每个风格给出情绪、色板、字体、图形语言、质感、适用场景与避坑点。色板为可直接起步的近似 hex，落地时按品牌微调。

## 1. 瑞士国际主义 / Swiss International

- 情绪：理性、可信、高级的克制
- 色板：#0F0F0F + #FFFFFF + 单一强调色（如 #E63946 或 #1D4ED8），大量留白
- 字体：Helvetica/Inter/思源黑体，全程无衬线，字号差拉大
- 语言：12 栏隐形网格、左对齐、细分割线、模块化排版、图片网格化裁切
- 质感：无渐变无阴影，平涂
- 适用：科技/SaaS、发布会、数据报告、财经
- 避坑：用网格就别居中；信息密度要够，空但不能虚

## 2. 现代编辑风 / Editorial

- 情绪：杂志感、观点感、有品味
- 色板：米白 #F7F4EE + 墨黑 #1A1A1A + 一个沉稳点缀（#8C2029 酒红 / #234069 花青）
- 字体：衬线大标题（Playfair/思源宋体）+ 无衬线正文（Inter/思源黑体）
- 语言：超大标题出血、窄栏、首字下沉、图文穿插、序号与栏目名
- 质感：哑光纸感、轻颗粒
- 适用：公众号头图、品牌故事、生活方式、文化活动
- 避坑：衬线只给标题和引语，正文保持无衬线

## 3. 极简留白 / Minimal

- 情绪：安静、自信、贵
- 色板：#FAFAF8 暖白 + #1C1C1C + 灰阶 + 单色点缀
- 字体：单家族多字重（思源黑/Inter），细字重可用
- 语言：一个主体 + 一片呼吸空间，元素不超过 3 组
- 质感：柔光、极淡阴影或无阴影
- 适用：高端产品、香氛、家居、珠宝、艺术展
- 避坑：极简不是空洞——主体质感必须极好，否则显廉价

## 4. 高奢黑金 / Luxurious

- 情绪：稀缺、仪式感
- 色板：#0A0A0A（不要纯黑）+ 香槟金 #C9A96A / #D4AF37 + 象牙白 #F5F0E6
- 字体：高对比衬线（Playfair/Cormorant/思源宋体细体）
- 语言：居中对称可用于此风格、细线框、大面积暗场、小字号大行距
- 质感：金属微渐变、丝绸反光、克制的聚光
- 适用：珠宝、酒水、高端地产、邀请函
- 避坑：金色面积要小（10% 法则），满屏金即土

## 5. 新中式 / 当代东方

- 情绪：文雅、静谧、当代的传统
- 色板：宣纸白 #F5F1E8 + 玄色 #201D1D + 宫墙红 #9D2933 / 花青 #234069，缃色点缀
- 字体：思源宋体/霞鹜文楷标题 + 思源黑正文；可竖排
- 语言：留白造境、瘦山石式分割、圆形/扇形窗棂、细金线、印章红块
- 质感：宣纸纤维、哑光、水墨晕染（极淡）
- 适用：茶饮、文创、文旅、月饼节礼、家居
- 避坑：不要堆龙凤祥云牡丹素材；元素减半才当代

## 6. 国潮 / 东方潮流

- 情绪：年轻、热闹、文化自信
- 色板：高对比撞色但取灰底——朱砂 #FF461F、宫墙红 #9D2933、藤黄 #FFB11E、花青 #234069、玄黑
- 字体：超粗黑体/仿宋标题，可做错位、描边、倾斜
- 语言：传统纹样（海浪/回纹/剪纸）扁平化重构、大字报式排版、边框装饰
- 质感：版画/丝网印颗粒、套色错位
- 适用：年轻消费品、节日营销、潮玩、食品饮料
- 避坑：元素要几何化重绘，直接贴图显老气；撞色控制在 2-3 色

## 7. 日式留白 / MuJI-like

- 情绪：素净、温和、日常之美
- 色板：生成色 #EDEAE0、暖灰、燕麦 #D8C9A8、鼠尾草绿 #A8B5A0
- 字体：思源宋体细体 / 信黑体，字号小、行距松
- 语言：大量余白、小图小字、低重心、竖排小字标签
- 质感：棉麻、原木、柔光、胶片低对比
- 适用：生活方式、母婴、烘焙、民宿、手作
- 避坑：商业转化信息（价格/CTA）仍需清晰，别全淡掉

## 8. 复古港风 / 港式霓虹

- 情绪：怀旧、烟火气、电影感
- 色板：墨绿 #0F3D3E、酒红 #7A1F2B、霓虹青 #2EE6C9 与品红 #FF2D78 做光
- 字体：思源宋粗体 / 明朝体，繁体可选
- 语言：招牌式横排、灯箱边框、做旧印刷、竖排招牌
- 质感：胶片颗粒、暗角、霓虹辉光、轻微色差
- 适用：餐饮、酒吧、市集、复古主题活动
- 避坑：霓虹只点 1-2 处，满屏光污染会失焦

## 9. 酸性平面 / Acid Graphics

- 情绪：前卫、迷幻、亚文化
- 色板：黑底 + 荧光绿 #CCFF00、电紫 #8B5CF6、液态金属银
- 字体：实验性可变字体、Chrome 立体字、尖锐衬线
- 语言：熔融 3D 字体、液态金属球、欧普纹理、网格扭曲、噪点
- 质感：镀铬反射、镭射、玻璃折射、颗粒
- 适用：音乐节、潮牌、数字艺术、夜店、Web3
- 避坑：可读性是底线，主信息不能被特效吞掉

## 10. Y2K 千禧复古

- 情绪：乐观、甜酷、互联网青春期
- 色板：糖果色 #FF8FCB、#7AD7F0、#C8B6FF 配银白
- 字体：圆润粗体、像素字点缀、Blade 标题
- 语言：半透明气泡、果冻按钮、金属心星、低分辨率拼贴、IE 窗口元素
- 质感：果冻高光、金属拉丝、闪粉
- 适用：年轻女装、美妆、二次元周边、怀旧营销
- 避坑：元素甜但配色要留呼吸区，否则发腻

## 11. 孟菲斯 / Memphis

- 情绪：活泼、顽皮、80 年代
- 色板：#FF5C8A、#FFD23F、#36C5F0、#43B929 + 黑描边
- 字体：粗圆无衬线
- 语言：波浪线、波点、三角、不规则色块、撞色边框、松散网格
- 质感：平涂为主，轻投影
- 适用：儿童、教育、活动促销、社交贴纸
- 避坑：元素控制密度，中文标题保持黑体重心压住画面

## 12. 包豪斯 / Bauhaus

- 情绪：几何、构成、功能美学
- 色板：三原色 #E63946/#F4C430/#1D4ED8 + 黑白灰
- 字体：无衬线几何体，全大写英文标签
- 语言：圆/三角/正方形的精确构成、粗黑线、不对称平衡
- 质感：完全平涂
- 适用：工业设计、建筑、设计周、技术品牌
- 避坑：几何元素要承担信息分区，不能只做装饰

## 13. 新粗野主义 / Neo-Brutalism

- 情绪：直白、大胆、互联网原生
- 色板：亮色底（#FFE15D/#8ED6FF）+ 黑字黑边
- 字体：等宽/极粗无衬线
- 语言：粗黑描边（2-4px）、硬阴影（无模糊 offset 阴影）、错位重叠、裸露网格线
- 质感：平、硬、无渐变
- 适用：独立产品、开发者工具、潮牌、活动 KV
- 避坑：中文慎用等宽混搭，黑体超粗即可；描边粗细全稿统一

## 14. 玻璃拟态 / Glassmorphism（克制使用）

- 情绪：轻盈、科技、通透
- 色板：柔和多彩渐变底（低饱和）+ 白色 8-15% 透明卡片
- 字体：细-中等字重无衬线
- 语言：模糊卡片层叠、1px 高光描边、浮岛布局
- 质感：背景虚化、细腻
- 适用：深色科技产品 UI、仪表盘视觉
- 避坑：已成 AI 默认套路——仅在深色彩底且确实需要分层时用，别拿来当万能风格

## 15. 赛博朋克 / Cyberpunk

- 情绪：未来、冷峻、都市夜景
- 色板：近黑 #0B0F1A + 青 #00F0FF + 品红 #FF2E97，少量警示黄
- 字体：工业无衬线/等宽，全大写英文，字间距拉开
- 语言：HUD 线框、故障错位、光效描边、网格透视
- 质感：雨夜反射、辉光、故障纹理
- 适用：游戏、科技发布、电竞、3C
- 避坑：辉光只给主标题和边缘，正文保持干净可读

## 16. 胶片纪实 / Film Editorial

- 情绪：真实、故事感、可信
- 色板：柯达暖调（#E8B574 高光、#4A3B32 暗部）或青橙电影调
- 字体：思源宋体或人文黑体，小字号
- 语言：大图压版、文字在画面留白处、细图注
- 质感：轻颗粒、暗角、低对比宽容度
- 适用：人物故事、旅行、餐饮、品牌纪录片式传播
- 避坑：调色后保证主体肤色与商品色不失真

## 17. 莫兰迪 / Morandi

- 情绪：温柔、安静、有教养
- 色板：灰粉 #C9A7A0、灰蓝 #93A5B4、灰绿 #A8B0A0、燕麦 #D6C9B0
- 字体：细宋或细黑
- 语言：同明度色块并置、柔和边界、留白
- 质感：哑光、微纹理
- 适用：家居、服饰、美妆、生活方式
- 避坑：对比太低会糊，用一个深色文字层保证阅读

## 18. 软 3D / Soft 3D Render

- 情绪：友好、立体、当代互联网
- 色板：奶油底 #FFF6EC + 高饱和但不刺眼的物体色
- 字体：圆润几何无衬线
- 语言：C4D 感圆角物体、膨胀字、等距视角、柔和接触阴影
- 质感：哑光塑料/黏土/充气材质、柔和棚光
- 适用：工具类产品引导页、节日运营、IP 形象
- 避坑：3D 物体风格要统一（全黏土或全充气不要混）

## 19. 克莱因蓝 / 单色宣言

- 情绪：艺术、强烈、极简的爆发力
- 色板：International Klein Blue #121E9E（或近 #1D2CF0）单色 + 黑白
- 字体：超粗无衬线或高对比衬线
- 语言：单色铺满、反白大字、单一主体剪影
- 质感：平涂或极轻肌理
- 适用：艺术展、品牌态度海报、封面
- 避坑：单色策略要求构图极强，普通促销信息撑不起来

## 20. 电商爆款 / Conversion Pop

- 情绪：直接、热闹、利益清晰
- 色板：红橙暖促销（#E63946/#FF7A00）或品牌强色 + 明黄价格底 #FFD23F
- 字体：超粗黑（数字用西文 900）
- 语言：大数字、角标、卖点不超过 3 个、主体占 60-75%
- 质感：干净棚拍或浅场景，弱投影
- 适用：主图、直通车、直播间贴片
- 避坑：促销签别贴成牛皮癣；信息按"主体→价格→1 个最强卖点→CTA"排序

## 风格组合建议

- 科技 To B：瑞士网格 + 单一强调色；最多加一点克制玻璃
- 新消费食品：国潮或胶片纪实，二选一，别同时
- 美妆：莫兰迪/极简 + 软 3D 点缀；或日式留白
- 3C/游戏：赛博或瑞士，按受众年龄分
- 文化/文旅：新中式或现代编辑风
- 大促转化：电商爆款骨，借品牌色做皮，别直接套淘宝通用红
