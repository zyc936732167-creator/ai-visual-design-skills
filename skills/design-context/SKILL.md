# Design Context（品牌设计上下文）

所有视觉技能共享的"品牌基调文件"。没有它，每张图都会各做各的；有了它，色、字、风格在所有物料中保持一致。

## Step 1: 收集（有什么用什么，不要审问用户）

按优先级获取：

1. 用户直接提供的 VI/品牌手册、Logo、官网、店铺、历史物料
2. 用户口述：行业、产品、目标人群、喜欢/讨厌的参考
3. 都没有：基于行业与人群给出 1 套克制的默认方案，并标注是假设、可改

需要确定 6 项：

| 项目 | 内容 |
|------|------|
| 品牌基本盘 | 名称、一句话定位、目标人群、使用场景（线上平台/线下印刷） |
| 主色板 | 主色/辅助色/强调色 hex + 黑白灰中性色；标注 60-30-10 |
| 字体 | 中文标题/正文字体栈、西文搭配；确认授权（详见 visual-art-director/references/chinese-typography.md） |
| 风格原型 | 从 style-taxonomy.md 锚定 1 个主风格 + 至多 1 个辅助气质 |
| 图形语言 | 形状气质（几何/有机）、圆角与描边尺度、图标风格、摄影或插画倾向 |
| 禁忌 | 不能出现的颜色、元素、字体、竞品联想、平台违禁词 |

## Step 2: 输出 design-context.md

在项目根目录写入以下模板（有信息填信息，没有给默认值并注明）：

```markdown
# Design Context

## 品牌
- 名称 / 定位 / 目标人群 / 主要发布平台：

## 色板（60-30-10）
- 主色（60%）：#______
- 辅助色（30%）：#______
- 强调色（10%，只给 CTA/价格/关键词）：#______
- 深色背景：#______（不要纯黑） / 浅色背景：#______（不要纯白）
- 文字主/次色：#______ / #______

## 字体
- 中文标题：'___', 'PingFang SC', 'Noto Sans SC', sans-serif
- 中文正文：同上或指定
- 西文/数字：Inter / Helvetica / Playfair …
- 授权状态：系统字体 / 免费商用 / 已采购

## 风格原型
- 主锚点（引用 style-taxonomy.md 的编号或名称）：
- 辅助气质：
- 情绪关键词（3 个）：

## 图形语言
- 形状 / 圆角 / 描边 / 图标风格 / 影像倾向：
- 光源习惯（如统一左上柔光）：

## 禁忌
- 颜色 / 元素 / 字体 / 文案红线：

## Logo 与资产
- Logo 文件位置、安全间距、最小尺寸、深色/浅色版本：
- 商品图/人物素材位置：
```

## Step 3: 默认兜底（用户完全没方向时）

- 色板：暖白 #FAF9F7 + 墨黑 #1C1C1C + 单一强调色（按行业从 color-palette Step 7 取）
- 字体：思源黑（系统兜底 PingFang SC / Microsoft YaHei）+ Inter 管数字
- 风格：瑞士国际主义网格或极简留白，二选一按行业
- 明确告诉用户这是可替换的默认基调，首次出图确认后锁定

## 维护规则

- 风格锁定后，后续所有视觉技能都读这个文件；用户要求"换个风格"时先改这里，再改图
- 新增物料只扩展不推翻：新增色必须说明角色（如"促销临时色"），防止色板失控
- 不要在这个文件里放具体海报文案——它管"怎么看"，不管"说什么"
